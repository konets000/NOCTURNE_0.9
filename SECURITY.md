# Security policy

### Reporting a vulnerability

Do not post exploitable details, private files, or proof-of-concept payloads in a public issue.

If private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability** on GitHub. If it is not, contact the maintainer through a publicly listed contact method and ask for a private disclosure channel.

Include the affected version or commit, the impact, reproduction steps, and platform details. Do not include personal subtitle files, audio, credentials, or signing material.

### Scope

NOCTURNE is a development preview. Its local-first design, Android permission boundary, and Windows loopback server are not a substitute for an independent security audit. Do not use it with sensitive material until you have reviewed and tested the build yourself.
